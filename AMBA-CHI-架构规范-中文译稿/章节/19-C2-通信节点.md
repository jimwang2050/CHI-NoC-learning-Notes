# C2 通信节点
本附录针对每种数据包类型，规定使用该数据包类型进行通信的节点。它包含以下小节：

- C2.1 请求通信节点
- C2.2 监听通信节点
- C2.3 响应通信节点
- C2.4 数据通信节点

### C2.1 请求通信节点

表 C2.1 列出了请求通信节点。在表 C2.1 中，除非另有明确说明，对写事务的引用既包括单个 Write 事务，也包括相应的 Combined Write 事务。
