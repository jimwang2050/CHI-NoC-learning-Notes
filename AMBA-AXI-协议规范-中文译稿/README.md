# AMBA AXI 协议规范（IHI0022L）中文译稿

Arm《AMBA AXI Protocol Specification》（IHI0022L，2025-08-27 发布）的中文译稿。保留原文的章节结构与图表，正文 16 章（A1–A16），附录 4 章（B1–B4），另附术语表（C1）。

- **术语**：管理者（Manager）指发起请求的一方，从属者（Subordinate）指响应请求的一方。这是 Arm 自 H.b 版起替换 Master / Slave 的用词，读旧资料时按此对应。
- **章节号**：沿用原书。`A` 部分是规范正文，`B` 部分是附录（信号列表、接口类、ID 约束、修订记录），`C` 部分为术语表。
- **页码**：下表页码为 Arm 原版 PDF 页码，可与官方英文版逐页对照；仓库内的排版 PDF 因重新排版，页数不同（372 页），但内容一致。
