
# CHI & NoC Learning Notes

AMBA CHI 与 NoC 学习笔记，主要用于整理 CHI 协议、NoC 基础、SoC 互联架构以及学习过程中的协议分析、模块理解和实验记录。

##  简介

本仓库用于系统学习 **AMBA CHI** 和 **NoC** 相关知识，整理协议要点、模块结构、数据流、一致性机制、事务类型以及 SoC 互联架构中的常见问题。

- CHI 请求、响应、数据流
- CHI 与 ACE/AXI 的关系
- CHI 协议时序与状态机分析

### NoC

- NoC 基本概念
- 路由器结构

- 路由算法
- 流控机制
- 虚拟通道
- 带宽、延迟、拥塞与死锁问题

### SoC Interconnect

- 一致性互联设计
- 缓存一致性基础

- 性能与带宽分析
